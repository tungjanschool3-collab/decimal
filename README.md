# ห้องทดลองเศษส่วนแสนสนุก

เว็บแอปภาษาไทยสำหรับสร้างภาพเศษส่วน เศษเกิน และจำนวนคละด้วยการลงสี

## ความสามารถ

- สร้างรูปแบบวงกลมและแถบ
- ปรับตัวเศษและตัวส่วน
- แสดงเศษเกินเป็นหลายรูป
- แปลงจำนวนคละเป็นเศษเกินพร้อมขั้นตอน
- เครื่องมือเขียนสูตรและแบบฝึกหัด
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## การเปิดใช้งาน

เปิดไฟล์ `index.html` หรือเปิดใช้งาน GitHub Pages จาก branch `main` และโฟลเดอร์ `/ (root)`
